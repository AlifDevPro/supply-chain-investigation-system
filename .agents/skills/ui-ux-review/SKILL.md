Read `docs/ui-ux-guidelines.md`. Review status/impact/owner/next action, evidence provenance, uncertainty, freshness and whether AI recommendations look approved. Check loading/empty/error/permission/stale states, keyboard use, labels, focus and contrast. Reuse existing shadcn/ui components. Avoid fake metrics, decorative charts and nonfunctional buttons. Report prioritized findings first; change code only when asked.

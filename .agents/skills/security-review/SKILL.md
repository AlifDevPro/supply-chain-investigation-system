---
name: security-review
description: Audit tenant isolation, approval, prompt injection, data exposure and tool safety.
---
Read `docs/security-threat-model.md`. Map trust boundaries. Inspect server-side authorization, untrusted document flow, tool permissions, approval binding/expiry/revalidation, idempotency, secrets/logging, input limits, retries and audit. Report severity, location, exploit scenario, impact and fix. Do not claim compliance certification or make broad fixes before approval.
